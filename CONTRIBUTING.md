# Contributing to the ZDD ASCII Gallery

Thanks for contributing.

## Contribution rules

1. Fork the repository.
2. Work on a dedicated feature branch.
3. Add exactly one file: `art/<your-github-username>.txt`.
4. Do not modify somebody else's artwork.
5. Build the site locally before opening the PR.
6. Keep the pull request focused on one contribution.
7. Respond to review feedback with additional commits on the same branch.

## Content rules

Contributions must be suitable for a university course website. No hateful, discriminatory, sexual, violent, privacy-invasive, or otherwise inappropriate material. Do not paste copyrighted artwork from elsewhere.

## Why one file per contributor?

This repository deliberately uses a modular contribution structure. Many contributors can work independently without editing one shared file. The Pages build collects the individual files automatically.
